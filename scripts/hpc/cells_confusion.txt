# T2_CONFUSION cells for eta_rung_confusion.slurm.  SEVEN fields per line:
#   MODEL TEMPLATE RUNGS EPOCHS RESTARTS N_ENS N_EXTRA
# (the base cells.txt has five; this rung needs the ensemble sizes per cell
#  because its EVAL error is tail-limited -- see README_T2_Confusion_v2.md Sec. 8)
# Lines starting with '#' are skipped; array index N runs the N-th non-comment line.
#
# WHY THE ENSEMBLES ARE SO MUCH LARGER THAN cells.txt.
# The compact template's MF output inherits the P(D) tail: measured excess
# kurtosis of the per-image MF amplitude is 8.8 (floored) and 91.0 (floorless),
# against ~1-3 for every other model in the campaign.  The relative standard
# error of an EVAL-split variance is sqrt((g2 + 2) / 4 n_eval), so
#     n_eval =  1 500 -> 4.4 % (floored compact) / 12.4 % (floorless)
#     n_eval =  7 500 -> 2.0 %                   /  5.6 %
#     n_eval = 15 000 -> 1.4 %                   /  3.9 %
# N_ENS = 30000 gives n_eval = 7500 under the standard 0.25/0.4/0.1/0.25 split.
# Do not economise here: at cells.txt sizes this rung cannot distinguish a
# ceiling of 1.0 from one of 1.5.
#
# N_EXTRA IS A DIFFERENT MATTER (revised 2026-09-04).  It feeds FIT/VAL, not EVAL,
# so it does nothing for the error bar; the first submission used 30000-40000 by
# symmetry with N_ENS and nothing else.  Cost is linear in n_fit, and the campaign's
# own GH200 cells fix the constant: a full 5-rung ladder at n_fit = 10800, 200
# epochs, 4 restarts took 3.46-3.50 h in four independent cells, i.e. 3156 s per
# restart (cubic 1696, cnn 771, quadratic 682, reweight 7, linear ~0).  At n_fit
# 27000 x 6 restarts that is 13.25 h -- past the 12 h wallclock, with TOTAL loss,
# because run_eta_campaign saves only after a cell's entire ladder finishes.
# Back to n_fit = 10800 (N_EXTRA 12000): 5.3 h, with better than 2x margin.
# Under-fitting cannot inflate a variational bound, only lower it, so this is the
# safe direction to economise in.
#
# --- the production row: the two cells that answer the paper's question ---
T2_CONFUSION_WN  extended  linear,reweight,quadratic,cubic,cnn  200 6 30000 12000
T2_CONFUSION_WN  compact   linear,reweight,quadratic,cubic,cnn  200 6 30000 12000
# --- the floorless diagnostic: expected to be ill-posed, run to SHOW it ---
# Sec. 4 of README_T2_Confusion_v2.md predicts these are not reproducible above
# k ~ 0.4 and that sigma_MF tracks the mode count.  Sec. 6.3 + the Method-C
# calculation predict eta is TEMPLATE-INDEPENDENT here (whitening a floorless
# confusion field returns the bare delta field, whose pixels are i.i.d.).
# These two cells test that prediction: they should agree with each other.
T2_CONFUSION     extended  linear,reweight,quadratic,cubic,cnn  200 6 30000 12000
T2_CONFUSION     compact   linear,reweight,quadratic,cubic,cnn  200 6 30000 12000
# --- T2_CONFUSION_ATM: the CALIBRATION cells (exact eta known) ---
# Beam-correlated companion at rho = 0.25, i.e. the same 0.5 sigma_c of Gaussian
# noise as the _WN row but sharing the beam.  Whitening returns i.i.d. pixels, so
# tools/eta_exact_confusion.py can state the answer in advance:
#     eta = 3.5688 exactly (converged 7e-5), complete-data bound exactly 5,
#     and the SAME value for both templates.
# Allowing for the float-rounding dilution measured on the M3 (eps = 0.0410 of the
# whitened variance, from two independent cumulant routes agreeing to 2.7%), the
# ladder should land on eta = 3.145 instead.  Either number is a result; landing
# on neither means the ladder is wrong, which is the point of the test.
# Sized generously at n_ens 60000 (n_eval 15000).  NOTE (corrected 2026-09-04): the
# original justification here cited the WHITENED FIELD's excess kurtosis of ~152, but
# the quantity that actually sets the EVAL error is the kurtosis of the MF OUTPUT
# y = t^.x, measured at 42.5 (compact) and 1.36 (extended) -- the extended template
# averages the pixel tails away.  For the linear rung the bound's standard error is
# exactly sqrt(g2(y) + 2)/sqrt(n_eval), so n_eval 15000 gives +/-0.055 (compact) and
# +/-0.015 (extended) against an exact eta of 3.5688 (3.1453 after the rounding
# dilution).  That is more headroom than strictly needed -- n_eval 6000 would already
# separate the two -- but the cells cost 5.4 h either way, so they are left generous.
T2_CONFUSION_ATM extended  linear,reweight,quadratic,cubic,cnn  200 6 60000 12000
T2_CONFUSION_ATM compact   linear,reweight,quadratic,cubic,cnn  200 6 60000 12000
# --- deep-rung repeats at doubled EVAL, only if 1-2 land near the anchor ---
# (submit as --array=5-6 after reading the first four)
T2_CONFUSION_WN  extended  cnn,cubic                            300 8 60000 12000
T2_CONFUSION_WN  compact   cnn,cubic                            300 8 60000 12000
